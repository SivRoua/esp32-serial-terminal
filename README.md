# Physical Serial Terminal

基于 ESP32-C3 的便携式物理串口终端项目。通过串口与目标设备通信，支持屏幕显示与键盘输入，适用于嵌入式设备调试和脱机终端操作。

## 硬件规格

- 主控芯片：ESP32-C3-WROOM-02-N4
- 显示模块：2.0 英寸 ST7789V IPS 显示屏 (240x320, SPI 接口)
- 输入设备：标准 PS/2 键盘 (Mini-DIN-6 接口)
- 通信接口：RS-232 接口 (DB9 / 排针)、USB-C 调试串口 (CH340N)
- 电源管理：USB-C 充电管理、单节 18650 锂电池供电与电源转换电路

## 开发环境

- 软件开发：ESP-IDF
- 硬件设计：EasyEDA Pro (嘉立创EDA专业版)
